# 🚗 Tracker de Mercado Automotriz

Un dashboard interactivo construido con Python y Streamlit diseñado para analizar tendencias, precios y depreciación en el mercado de autos usados. 

Este proyecto sigue la filosofía **"Start Small, Scale Big"**, comenzando con análisis estáticos y escalando hacia extracción de datos automatizada y modelos predictivos.

---

## 📋 Características Actuales (Fase 1)

* **Carga de Datos:** Permite a los usuarios subir su propio inventario en formato CSV.
* **Filtros Dinámicos:** Barra lateral interactiva para filtrar el análisis por marca de vehículo.
* **Visualizaciones Interactivas (Plotly):**
  * Gráfico de cajas (Box plot) para entender la distribución de precios según el año de fabricación.
  * Gráfico de dispersión (Scatter plot) para analizar la depreciación basada en el kilometraje.
* **Métricas Clave:** Cálculo automático del precio promedio global, kilometraje promedio y total de vehículos en el set de datos.

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.x**
* **Streamlit:** Para la interfaz de usuario web.
* **Pandas:** Para la limpieza y manipulación de datos.
* **Plotly Express:** Para las visualizaciones interactivas.
